# Usman HVAC Tech website
Static HTML/CSS/JS, no build step.

## Deploy
1. Push these files to a GitHub repo.
2. Cloudflare dashboard > Workers & Pages > Create > Pages > Connect to Git.
3. Framework preset: None. Build command: (empty). Output directory: `/`.

## Before launch
- Replace placeholder email `info@usmanhvactech.com` (search all files).
- Replace `https://usmanhvac.pages.dev` in sitemap.xml, robots.txt and index.html JSON-LD with the real domain.
- Booking form opens WhatsApp or the email app; no backend needed.
